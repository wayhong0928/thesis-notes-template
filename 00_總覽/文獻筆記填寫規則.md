# 文獻筆記填寫規則

第二章會直接從文獻筆記取材，所以筆記的原則是：**寧可寫 TBD，也不能寫錯。** 自己寫、請 AI 寫都照這份。

## 一、選哪一型

| 文獻性質 | 模板 |
|---|---|
| 問卷、實驗、縱貫、質性、量表開發、混合方法 | `07_模板/03_文獻筆記_實證型` |
| 提出或更新理論、敘述性回顧、系統性回顧、後設分析、書籍 | `07_模板/03_文獻筆記_理論型` |
| 統計方法、效度判準、共同方法偏誤、中介分析等方法論文獻 | `07_模板/03_文獻筆記_方法型` |

類型看內容，不看期刊標籤。期刊標成 review、但內容是提出新架構，而且沒有檢索程序與納入標準，就用理論型，「回顧範圍」寫「非系統性回顧，未報告檢索程序」。

檔名用 citekey（例：`Davis1989.md`），跟 Zotero 一字不差。章節標題照模板，不新增章節；「我的批判」的限制可以多於兩條。

## 二、通用規則

- **頁碼**：每個數字、定義、作者主張都附頁碼，格式 `（PDF p. 5）`，指 PDF 檔的第幾頁（不是期刊印的頁碼，兩者常常不同）。句子跨頁寫 `（PDF p. 4–5）`。要直接引用時，另外記下期刊印的頁碼，APA 引文用得到。查不到頁碼但確定原文有寫，標「頁碼待查」，不要自己編。
- **數字**：照原文抄，小數位數、正負號、星號都不改。原文自己前後對不上時，每個版本都記下並各附頁碼，加註「原文數字不一致」，不要自己挑一個。只有「同一個量、同一個量尺、同一個樣本」在原文兩處對不上才算矛盾；量尺或來源不同（人數對平均、平均對總分、原量表信度對本樣本信度）寫「原文未說明」，不要自己換算後說它矛盾。
- **TBD 和 N/A**：欄位適用但原文找不到，填 `TBD`；這類論文本質上不會有這一欄，填 `N/A`。不要用推測填空，也不要用記憶補原文沒寫的東西。
- **構念照原文翻**：原論文的構念照它自己的定義翻譯，不要改寫成你研究的構念名稱。兩者的對應只寫在變項表的「對應本研究構念」欄，並寫出相同與不同之處。譯名先查 `00_總覽/術語表.md`。
- **不寫你自己的假說編號**：文獻筆記只記原論文自己的假說與結果（用原文編號）。你的假說編號只出現在 `研究設計速查.md` 和推演卡的 `hypothesis` 欄。這樣假說改版、重新編號時，文獻筆記一份都不用動。
- **直接引用**：只放在「可引用的發現」，用「」框起原文並附頁碼，一篇最多 3 句。其他地方一律改寫。
- **作者說的和你說的分開**：「作者指出的缺口」「作者自述的限制」只寫作者自己寫的，附頁碼；你的看法放「我的批判」。

## 三、證據強度用詞

描述原論文的發現時，用詞跟著它的研究設計走：

| 研究設計 | 可以寫 | 不要寫 |
|---|---|---|
| 實驗、縱貫 | 影響、提高、降低 | 導致（除非作者自己這樣下結論） |
| 橫斷面問卷 | 預測、與……相關、與……有關聯 | 影響、導致、造成 |
| 質性研究 | 反映、受訪者描述 | 證實、證明 |
| 作者的推論 | 作者推測、可能 | 研究發現、證實 |

## 四、`連結的概念筆記` 怎麼連

- 只連到 `01_理論/`、`02_變數/`、`06_方法/` 裡**實際存在**的檔名。
- 只有原論文構念跟你的構念指的是同一件事（同一理論傳統的定義與量表），或屬於公認的對應構念，才連。測量對象或情境不同（例如原文測某資訊系統、你測生成式 AI）算同構念，照連，差異寫在變項表。
- 定義不同、量表與維度不同、只是理論上相關的構念，不連，差異寫在變項表就好。
- 理論型文獻只連原文直接討論的構念；方法型文獻填 `[]`。
- `文獻矩陣.base` 的「斷掉的連結」欄會列出指到不存在檔案的連結，打開就看得到。

## 五、實證型逐欄重點

| 欄位 | 怎麼填 |
|---|---|
| 一句話結論 | 60 字以內：對象＋最主要的發現＋一個關鍵數字。不加評價 |
| 速覽 | 每格一行。「樣本數」寫有效樣本；「變項」寫構念總數，並分列自變數、中介、調節、依變數各幾個；「假說結果」要和第五節表格一致 |
| 變項表 | 列出模型裡**所有**構念，含控制變項 |
| 測量品質 | 寫信度、收斂效度、區別效度的指標與數值範圍，例「α 為 .82 至 .91」，並寫是否達到作者採用的門檻 |
| 研究結果表 | 原論文檢驗的**每一條**假說或路徑都列，不挑重點。沒有正式假說時，每列是一項檢驗或一個研究問題的發現 |
| 不顯著或與預期相反的結果 | 必填。全部成立就寫「全部成立」 |
| 我的批判 | 寫方法層次的問題：構念效度、內部效度、外部效度、共同方法偏誤、樣本與情境落差。不要照抄作者自述的限制 |
| 在論證中的位置 | 擇一或多個並說明理由：現象描述、前因證據、機制證據、研究缺口、情境對照、測量來源、方法依據、反例 |
| 它做到的與沒做到的 | 「做到的」是你可以直接站上去的部分；「沒做到的」是它沒檢驗、而你的研究有檢驗的部分。只寫原文撐得住的差異 |
| 可引用的發現 | 2 至 4 條可以放進正文的中文句子，附（作者，年份）與頁碼，遵守第三節用詞 |

理論型的「構成要素」表，一列對應原文模型圖或文字明確命名的一個成分，每個定義附頁碼；「版本演進」只寫原文提到的前身與修訂。方法型的「判準與門檻值」每一列都附頁碼，並寫清楚是嚴格或寬鬆標準。

- [ ] 研究結果表的列數＝原論文檢驗的假說或路徑數，速覽的成立數跟表格一致
- [ ] 原論文構念沒有被改名成你的構念
- [ ] 缺口、限制、未來研究都找得到標示的頁碼
- [ ] 「可引用的發現」沒有寫得比原研究設計更強
- [ ] 沒有你自己的假說編號
- [ ] `連結的概念筆記` 都指到存在的檔案（看文獻矩陣的「斷掉的連結」欄）
- [ ] 檢查完把 `verified` 填上今天日期
